Format Response API (BERLAKU UNTUK SEMUA ENDPOINT):
  Sukses:   { success: true,  message: "...", data: { ... } }
  Error:    { success: false, message: "...", errors?: { ... } }
  Paginasi: { success: true,  message: "...", data: [...], meta: { page, limit, total, totalPages } }

Autentikasi: Bearer Token di Header
  Authorization: Bearer <accessToken>
  401 = token invalid/expired → interceptor otomatis refresh
  429 = rate limited → tampilkan pesan "Terlalu banyak percobaan"

FASE 1: AUTENTIKASI (LOGIN, REGISTER, GANTI PASSWORD)
================================================================================

Dokumentasi API:

  1. POST /api/auth/register
     Auth: TIDAK PERLU
     Body: { nama: string(3-100), email: string(email), password: string(6-100) }
     Sukses 201: { data: { id, nama, email, kategori, created_at } }
     Error 409: "Email sudah terdaftar"

  2. POST /api/auth/login
     Auth: TIDAK PERLU
     Body: { email: string, password: string }
     Sukses 200: { data: { user: {id,nama,email,kategori}, accessToken, refreshToken } }
     Error 401: "Email atau password salah"
     Error 403: "Akun Anda telah dinonaktifkan"

  3. POST /api/auth/refresh-token
     Auth: TIDAK PERLU (kirim refreshToken di body)
     Body: { refreshToken: string }
     Sukses 200: { data: { accessToken: "..." } }
     Note: Sudah auto-handle oleh axios interceptor

  4. GET /api/auth/me
     Auth: WAJIB token
     Sukses 200: { data: { id, nama, email, kategori, avatar, is_active, created_at } }

  5. PUT /api/auth/change-password
     Auth: WAJIB token
     Body: { old_password: string, new_password: string(6-100) }
     Sukses 200: { data: null, message: "Password berhasil diubah" }
     Error 401: "Password lama tidak cocok"

[ ] 1.1 - Buat API Service: src/api/auth.ts
    ```ts
    import api from './axios';
    import type { ApiResponse, LoginResponse, User } from '../types';

    export const authApi = {
      register: (data: { nama: string; email: string; password: string }) =>
        api.post<ApiResponse<User>>('/auth/register', data),
      login: (data: { email: string; password: string }) =>
        api.post<ApiResponse<LoginResponse>>('/auth/login', data),
      getMe: () => api.get<ApiResponse<User>>('/auth/me'),
      changePassword: (data: { old_password: string; new_password: string }) =>
        api.put<ApiResponse<null>>('/auth/change-password', data),
    };
    ```

FASE 4: DAFTAR UJIAN & SIMULASI UJIAN
================================================================================

Dokumentasi API:

  1. GET /api/ujian
     Auth: WAJIB token
     Query: ?page=1&limit=10&tipe=TRYOUT
     Sukses: { data: [{ id, nama, deskripsi, durasi_menit, tipe, peruntukan, is_active, _count: {ujian_soal} }], meta }

  2. GET /api/ujian/:id
     Auth: WAJIB token
     Sukses: { data: { id, nama, deskripsi, durasi_menit, tipe, peruntukan, ... } }

  3. POST /api/ujian/simulasi/mulai
     Auth: WAJIB token
     Body: { ujian_id: number }
     Sukses 200: { data: { hasil_ujian_id, sesi_ujian_id, sisa_waktu_detik, total_soal, soal_list: [...] } }
     Error 400: "Masih ada ujian yang berlangsung" / "Ujian Premium, upgrade akun"
     soal_list berisi: { ujian_soal_id, nomor_urut, pertanyaan, pertanyaan_gambar,
                         opsi_a, opsi_a_gambar, ..., opsi_e, opsi_e_gambar,
                         kategori_soal: {kode, nama} }

  4. POST /api/ujian/simulasi/heartbeat
     Auth: WAJIB token
     Body: { hasil_ujian_id: number }
     Sukses: { data: { sisa_waktu_detik, status: "AKTIF"|"TIMEOUT" } }
     PENTING: Kirim setiap 30 detik. Jika tidak heartbeat 120 detik → auto TIMEOUT

  5. POST /api/ujian/simulasi/jawab
     Auth: WAJIB token
     Body: { hasil_ujian_id, ujian_soal_id, jawaban: "A"|"B"|"C"|"D"|"E"|null, is_ragu: boolean }
     Sukses: { data: { ujian_soal_id, jawaban_user, is_ragu, totalTerjawab, totalBelumJawab, totalRagu } }

  6. POST /api/ujian/simulasi/selesai
     Auth: WAJIB token
     Body: { hasil_ujian_id: number }
     Sukses: { data: { hasil_ujian_id, status, waktu_mulai, waktu_selesai, durasi_pengerjaan_detik,
               total_soal, jumlah_dijawab, jumlah_benar, jumlah_salah, jumlah_kosong,
               skor_tiu, skor_twk, skor_tkp, skor_total, is_lulus,
               detail_kategori: [{ kode, nama, skor, passing_grade, lulus }] } }

================================================================================
CATATAN TEKNIS PENTING
================================================================================

1. GAMBAR/FILE STATIC
   Database menyimpan path relatif: "uploads/soal/abc.jpg"
   URL di frontend: /static/uploads/soal/abc.jpg
   Tag HTML: <img src="/static/uploads/soal/abc.jpg" />
   Jika field null → JANGAN tampilkan <img>

2. PAGINATION
   Backend menerima: ?page=1&limit=10 (default page=1, limit=10, max=100)
   Response.meta: { page, limit, total, totalPages }

3. ENUM VALUES
   UserKategori: FREE, PREMIUM
   TipeUjian: TRYOUT, LATIHAN, QUIZ
   PeruntukanUjian: FREE, PREMIUM, ALL
   LevelSoal: MUDAH, SEDANG, SULIT, HOST
   JawabanOpsi: A, B, C, D, E
   JenisKelamin: LAKI_LAKI, PEREMPUAN
   JenisLaporan: JAWABAN_SALAH, SOAL_SALAH, TYPO, PEMBAHASAN_SALAH, GAMBAR_RUSAK, DUPLIKAT, LAINNYA
   StatusKontribusi: PENDING, APPROVED, REJECTED
   StatusLaporan: PENDING, DITINJAU, DIPERBAIKI, DITOLAK
   StatusHasilUjian: BERLANGSUNG, SELESAI, TIMEOUT
   TingkatPenguasaan: BELUM, RENDAH, SEDANG, TINGGI, MAHIR
   AdminRole: SUPER_ADMIN, ADMIN

4. RATE LIMITING
   Auth endpoints: max 15 request per 15 menit
   All API: max 100 request per 1 menit
   Error 429 → tampilkan "Terlalu banyak percobaan"

5. TOKEN
   accessToken: berlaku 1 hari, refreshToken: berlaku 7 hari
   Simpan di localStorage (key: 'accessToken', 'refreshToken')
   Auto-refresh sudah di-handle oleh interceptor

6. HEARTBEAT UJIAN
   Kirim setiap 30 detik (HEARTBEAT_INTERVAL_SECONDS)
   Timeout jika 120 detik tidak heartbeat (HEARTBEAT_TIMEOUT_SECONDS)

7. FILE UPLOAD
   Max size: 2MB, Format: .jpg, .jpeg saja
   Validasi di frontend sebelum upload:
   if (file.size > 2*1024*1024) → "File terlalu besar (maks 2MB)"
